# Security policy

Please report a security or privacy issue through [GitHub's private vulnerability reporting](https://github.com/cylmio/signal-monitor/security/advisories/new) rather than opening a public issue. Include the Signal Monitor version, macOS version, reproduction steps, and the diagnostics report when safe to share. Do not include prompts, source code, credentials, or private task titles.

Only the latest released version is supported. Signal Monitor modifies `~/.codex/hooks.json` only after user confirmation, creates a timestamped backup, marks its own entries, and preserves unrelated hook entries.
